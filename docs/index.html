插件介绍

「每日成长」帮助你用最小的操作，坚持每天的小目标。无需账号、无需联网同步，打开弹窗即可打卡；跨日后自动刷新当日进度，习惯列表会一直保留。

使用教程

下载压缩包后，在 Chrome 中以开发者模式加载即可使用。

  1. 1

    下载插件

    点击下方按钮，下载 daily-growth-extension.zip 到本地。

  2. 2

    解压文件夹

    解压后得到 daily-growth-extension 文件夹，其中包含 manifest.json 等文件。

  3. 3

    打开扩展程序页

    在 Chrome 地址栏输入 chrome://extensions/，打开右上角「开发者模式」。

  4. 4

    加载并开始打卡

    选择「加载已解压的扩展程序」，选中解压后的文件夹。工具栏出现图标后即可添加习惯并打卡。
